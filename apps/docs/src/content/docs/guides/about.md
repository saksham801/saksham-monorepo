These notes are a working system, not a finished book. They capture the useful parts of building and running software: decisions, repeatable workflows, and references that save time later.

## How to use this site

- **Guides** explain a process from start to finish.
- **Reference** pages are compact, searchable answers.
- **Self notes** capture lessons and principles that are still evolving.

Every page aims to be direct, copyable, and honest about its trade-offs. If a recommendation depends on context, that context is included instead of hiding behind a universal rule.

## Writing principles

1. Prefer a small example over a large abstraction.
2. Document the failure mode, not only the happy path.
3. Keep setup and deployment instructions reproducible.
4. Update notes when the tools or assumptions change.

The site is built with Astro and Starlight, deployed as a static-friendly Cloudflare application, and styled with the same dark, high-contrast design language as [sakshampy.in](https://sakshampy.in).
